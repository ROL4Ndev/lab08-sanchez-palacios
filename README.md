# Laboratorio 07 - Sistema de Inventario con Node.js, Express y MongoDB

Este proyecto corresponde al desarrollo práctico del **Laboratorio N° 07** para el curso de **Bases de Datos Avanzadas**. Consiste en un sistema de gestión de inventario para una tienda web construida con **Node.js**, **Express**, **Mongoose** y el motor de plantillas **EJS**.
